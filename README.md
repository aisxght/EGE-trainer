# Тренажёр ЕГЭ по русскому языку

Версия **1.0.0**.

## GitHub Pages

Адрес сайта после публикации: https://aisxght.github.io/EGE-trainer/.

Workflow `.github/workflows/pages.yml` при обновлении `main` импортирует проверенную базу, запускает тесты, собирает сайт и публикует его в GitHub Pages. В настройках репозитория Pages должен быть выбран источник **GitHub Actions**.

`npm run build:pages` создаёт статическую сборку с путями `/EGE-trainer/`. В GitHub Actions имя репозитория берётся из `GITHUB_REPOSITORY`. Обычный `npm run build` по-прежнему собирает приложение для локального Go-сервера.

На Pages используется база слов, включённая в сборку; запросы к Go API отключены. Квизы, пары и сохранение прогресса работают в браузере. Прогресс на публичном сайте хранится отдельно от localhost и между устройствами не синхронизируется.

Обычный компонентный проект: **Vue 3 + Vite + TypeScript + Vuetify 3**, Node.js для инструментов и импорта; бэкенд на **Go** без внешних зависимостей. Nuxt не добавлен: для этого приложения выбрана запрошенная структура с Vue-компонентами и Vite, без серверного рендеринга.

## Запуск

Требования: Node.js 22.12+ и Go 1.22+.

```powershell
npm install
npm run build
go run ./server
```

Открыть http://127.0.0.1:8080. Go отдаёт и сайт из `dist/`, и API.

Для разработки запустить в двух терминалах:

```powershell
go run ./server
```

```powershell
npm run dev
```

Адрес Vite: http://127.0.0.1:5173, запросы `/api` перенаправляются на Go :8080. Если API недоступен, приложение использует ту же базу из сборки. На странице базы показан текущий источник.

## Что реализовано

- Главная: темы, статистика, дневная цель в 10 ответов и серия занятий.
- Ударение → квизы: выбор ударной гласной прямо в слове, 5/10/20 вопросов, обратная связь, результаты, повтор ошибок. Режимы частых и редких слов выбирают нужное число записей по количеству вариантов исходной базы, в которых встречается слово; при одинаковой частоте выбор случайный. Внешняя статистика не используется.
- Полный круг: вся база в случайном порядке, без повторов. Бесконечный режим: вся база без повторов внутри каждого круга, новое перемешивание на каждом круге, без немедленного повтора на границе. Кнопка «Завершить» показывает результат по отвеченным вопросам. Оба формата используют все слова независимо от прежнего фильтра; повтор ошибок после результата всегда конечный.
- Ударение → запоминалка: пары с одинаковой частью от ударной гласной до конца слова, скрытый ответ, перемешивание. Фильтры «Все пары», «Мои ошибки» и «Чаще всего ошибаюсь»; последний упорядочивает пары по сумме накопленных ошибок в двух словах. Перемешивание в нём меняет порядок только при равном числе ошибок. Ошибки в слове с предлогом учитываются для того же слова без предлога. Если созвучной пары в базе нет, новые слова не добавляются.
- База: поиск, пагинация, фильтр ошибок, список противоречий с точными строками источника.
- Правописание → в корне / в приставке / в суффиксе: заготовки до появления проверенных заданий.
- Адаптивная вёрстка и меню для телефона. Прогресс хранится локально в текущем браузере, без аккаунта и синхронизации.

Счётчики ошибок по словам сохраняются в `mistakeCounts` внутри прежнего ключа `tochka-progress-v1`. Правильный ответ очищает текущую отметку ошибки, сохраняя накопленный счётчик. До добавления счётчиков точная частота ошибок не записывалась: прежние отметки остаются доступными, но исторические числа не выдумываются. Сброс прогресса очищает и счётчики.

## Источник и обновление слов

Единственный исходный источник — `data/ege_udarenia_2023_2026_obshchaya.md`, копия предоставленного общего файла за 2023–2026 годы. Предыдущая версия сохранена в `data/archive/` и не участвует в импорте, чтобы не дублировать исходные строки. Слова из интернета не добавляются. Инструкции в Markdown не исполняются. Для тренировки выбора гласной используется **только правый столбец «Правильно»**. Ключи «Ответ» относятся к исходным вариантам из пяти слов и в данном формате не применяются.

Добавьте новые проверенные файлы `.md` в `data/` с форматом:

```text
## 2026 год
### 1. Ответ: 1
туфлЯ | тУфля
```

Ровно одна заглавная гласная справа обозначает ударение. Контекст омонимов можно указывать в скобках. Год и номер варианта необязательны, но помогают прослеживать происхождение.

```powershell
npm run import:words
npm test
npm run build
go test ./server
```

После импорта перезапустите Go, поскольку `server/words.json` встраивается в бинарный файл через `go:embed`. Импорт обновляет `src/words.json` и `server/words.json`. Не редактируйте их вручную. Для исполняемого сервера: `go build -o tochka.exe ./server`, затем `./tochka.exe`; папка `dist/` должна находиться в рабочей папке, либо задайте `-dist`.

Повторы объединяются с сохранением всех ссылок на строки. Разные ударения для одного слова и значения **исключают слово целиком из тренировки**, не выбирая ответ автоматически. Исправления вносятся во все противоречащие исходные строки, после чего выполняется повторный импорт. Неверный формат или несколько ударных гласных останавливают импорт до записи новой базы.

После уточнения по предоставленным пользователем изображениям в 720 строках остаётся один конфликт:

| Слово | Варианты правого столбца |
| --- | --- |
| послала | послалА / послАла |

Слово «послала» сохранено для проверки и не попадает в квизы и пары. В текущей тренировочной базе **208 уникальных записей**. Ошибочная расшифровка «запломбИровать» в варианте 29 за 2026 год исправлена на «запломбировАть» по изображениям пользователя. По запросу пользователя также исправлены пять записей «каплянуть» на «кАшлянуть», ударение сверено по Большому орфоэпическому словарю на «Грамоте». Основания исправлений записаны в `data/corrections/2026-10-26.md`. Проверка импорта обнаруживает внутренние противоречия, но не подтверждает лингвистическую правильность остальных непротиворечивых строк: приложение доверяет предоставленному правому столбцу.

Пары — мнемонический приём по созвучию, а не морфологический анализ или общее правило ударения. В пары не добавляются слова, отсутствующие в исходнике.

## Проверки и API

`npm test` проверяет импорт, конфликты, повторы, контекст, букву ё и полноту исходных данных. `go test ./server` проверяет выдачу базы, исключение конфликтов, методы и неизвестные API-маршруты. `npm run build` включает строгую проверку TypeScript.

- `GET /api/health` — состояние сервера.
- `GET /api/words` — база с источниками и списком конфликтов.

Go по умолчанию слушает только `127.0.0.1:8080`; адрес меняется флагом `-addr`. Используются локальные иконки MDI; шрифт Golos Text загружается из Google Fonts с локальным запасным шрифтом Arial.
